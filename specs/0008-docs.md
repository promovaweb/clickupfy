# 0008 Docs e páginas

Status: draft

## Goal

Ler e manter Docs do ClickUp, como os Docs de projeto do Hub.

## Behavior

`doc list|get|create` e `doc page list|get|tree|create|update` com as options do 0.9.0, conteúdo em Markdown por argumento, arquivo ou stdin.

## Design

Módulo `src/clickup/docs.ts`. Referência: `legacy/src/cli.ts` (doc), `legacy/src/arquivos.ts`.

## Surface

- Adiciona os commands `doc` e `doc page` com seus verbos.
- Adiciona as tools `clickupfy_docs_list`, `clickupfy_doc_get`, `clickupfy_doc_create`, `clickupfy_doc_pages_list`, `clickupfy_doc_page_get`, `clickupfy_doc_page_tree`, `clickupfy_doc_page_create` e `clickupfy_doc_page_update`.
