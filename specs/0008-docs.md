# 0008 Docs e páginas

Status: done

## Goal

Ler e manter Docs do ClickUp, como os Docs de projeto do Hub.

## Behavior

Docs ficam na API v3 sob o workspace do perfil (`/workspaces/{id}/docs`).

- `doc list` segue o `next_cursor` até `--max-pages` (1 a 50, padrão 50) e
  filtra por `--query` no id ou no nome, localmente.
- `doc create` exige `--parent-type` junto de `--parent-id` (sai com 2 sem
  ele) e envia `name`, `parent`, `visibility` e `create_page`.
- `doc page list|get` aceitam `--content-format` (`text/md`, padrão, ou
  `text/plain`); `doc page get` em texto imprime só o conteúdo.
- `doc page tree` mostra a árvore sem conteúdo; em texto, indentada.
- `doc page create|update` recebem o conteúdo por `--content`, por arquivo
  (`--file <path>`, com BOM removido) ou por `stdin` (`--file -`).
  `--content` e `--file` juntos saem com 2; arquivo inexistente sai com 6.
  `--file` existe só no CLI.
- `doc page update` exige `--name`, `--sub-title`, `--content` ou `--file`
  (sai com 2 sem nenhum) e aceita `--content-edit-mode` `replace`
  (padrão), `append` ou `prepend`.

## Design

Módulo `src/clickup/docs.ts`: funções de domínio com `client.requestV3`
(`listDocs`, `getDoc`, `createDoc`, `getPageTree`, `listPages`, `getPage`,
`createPage`, `updatePage`, `resolveContent`) e o array `docOperations`,
registrado em `src/operations/index.ts` com os grupos `doc` e `doc page`.
O `stdin` é lido com `readStdin` de `src/cli/input.ts`. Referência:
`legacy/src/cli.ts` (doc), `legacy/src/clickup.ts` e `legacy/src/arquivos.ts`.

## Surface

| Command | Função | Options | data no `--json` | Exit codes |
| --- | --- | --- | --- | --- |
| `doc list` (alias `ls`) | Busca Docs | `--query`, `--parent-id`, `--parent-type`, `--deleted`, `--archived`, `--creator`, `--max-pages` | `{ docs[] }` | 2, 3, 4, 5, 6 |
| `doc get <doc-id>` | Metadados do Doc | nenhuma | o Doc | 3, 4, 5, 6 |
| `doc create` | Cria um Doc | `--name` (obrigatória), `--parent-id`, `--parent-type`, `--visibility`, `--create-page` | o Doc | 2, 3, 4, 5, 6 |
| `doc page list <doc-id>` (alias `ls`) | Páginas com conteúdo | `--max-page-depth`, `--content-format` | `{ pages[] }` | 2, 3, 4, 5, 6 |
| `doc page get <doc-id> <page-id>` | Uma página | `--content-format` | a página | 3, 4, 5, 6 |
| `doc page tree <doc-id>` | Árvore de páginas | nenhuma | `{ pages[] }` | 3, 4, 5, 6 |
| `doc page create <doc-id>` | Cria página ou sub-página | `--name` (obrigatória), `--content`, `--file`, `--sub-title`, `--parent-page`, `--orderindex`, `--content-format` | a página | 2, 3, 4, 5, 6, 7 |
| `doc page update <doc-id> <page-id>` | Atualiza a página | `--name`, `--sub-title`, `--content`, `--file`, `--content-edit-mode`, `--content-format` | a página | 2, 3, 4, 5, 6, 7 |
